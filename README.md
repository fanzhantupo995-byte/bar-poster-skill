# bar-poster-skill

夜店海报设计 Skill：沉淀夜店活动海报的设计方法论与工作流程，供 AI 设计助手使用。

**概念界定**：这里的「夜店」指电音酒吧（Club）和 Livehouse 两类场所，不含清吧、精酿等静吧场景。

## 结构

- `SKILL.md` — Skill 主文件：触发条件、设计流程、风格体系、输出规范
- `references/` — Skill 知识文件：类型理解、视觉提炼维度、Prompt 模板、交付规范

> 参考图不进仓库：参考图仅作临时视觉分析使用，分析产出为文字笔记，图片本身不存储在仓库中。参考图可通过网络搜索（MCP、CLI、浏览器等任意可用方式）获取或由用户提供，关键词见 `references/search-keywords.md`。
