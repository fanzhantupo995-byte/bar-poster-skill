# 交付规范

## 输出物

1. **海报背景图**：无文字，含视觉氛围与融合元素
2. **排版建议说明**：可选的排版位置建议，供用户参考

## 尺寸规格（按需选择）

| 用途 | 画幅 | 建议像素 |
|---|---|---|
| 手机端传播（朋友圈 / 小红书） | 9:16 | 1080 × 1920 |
| 社交媒体方形 | 1:1 | 1080 × 1080 |
| 横版推送封面 | 16:9 | 1920 × 1080 |
| 印刷海报 | 3:4 / 2:3 | 300dpi，按实际尺寸 |

## 生成注意事项

- 生图时统一加 `no text`，避免模型生成乱码文字
- **不要刻意在 Prompt 中要求留白区或 clean area**——文字可以直接叠加在画面元素之上，留白反而会破坏画面完整性
- 只有当用户明确要求某个位置需要干净背景时，才在 Prompt 中引导该区域的画面弱化
- 排版建议（可选）：背景图输出后，可根据画面结构给出文字可放置的位置建议（如压在人物上、叠在光效区、置于底部信息栏），但仅作参考，不构成画面设计的约束
