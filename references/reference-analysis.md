# 参考图学习笔记（花瓣采集分析）

> 来源：花瓣网搜索「酒吧海报」等关键词的实际采集样本。仅文字分析，不存图。分析目的：明确各海报类型的视觉套路，供设计时套用。

## 从样本中明确的类型套路

### 1. 嘉宾海报（DJ / 特邀嘉宾）

样本特征：人物写真占画面 70% 以上，背景为风格化人工场景，非真实夜店环境。

常见四种风格方向：

| 风格 | 视觉元素 | 色调 |
|---|---|---|
| 复古巴洛克 | 欧式雕花金框、油画质感、棋盘格地面、藤蔓 | 暖金、酒红、褐 |
| Y2K 银紫 | 金属银元素、紫色渐变大字、玻璃/水滴质感、贴纸感排版 | 灰白底 + 紫渐变 |
| 流体金属 | 水银/铬金属流体环绕人物、球形金属点缀 | 黑 + 铬银 + 红光 |
| 精灵幻想 | 发光蝴蝶翅膀、纱裙、花卉、星光粒子 | 梦幻蓝、冰蓝 |

结构公式：顶部品牌 Logo → 人物居中/居下 70% → 嘉宾名大字压在人物下方 1/3 → 信息栏最底部

### 2. 酒水套餐 / 福利海报

样本特征：产品是绝对 C 位，排版结构化、信息密度高，两种气质：

- **高级质感型**：深棕/黑底、原木/岩石/丝绒场景、暖金光、干邑白兰地、金色花卉点缀 —— 适合威士忌/干邑
- **促销活泼型**：霓虹粉挂牌卡券造型、橙红色圆形展台、撞色高饱和 —— 适合啤酒/套餐促销

结构公式：顶部品牌 Logo → 大字标题（Benefits / Package / 套餐名）→ 产品 C 位（展台或卡券内）→ 价格/规则信息卡片区 → 底部信息栏

### 3. 收官 / 月底压轴海报

样本特征：中式庆典风格——红金醒狮、灯笼、金色书法大字、高饱和红金对撞，气势压场。

结构公式：主视觉（醒狮/庆典元素）铺满 → 书法大字标题压中下部 → 日期 → 底部信息栏

### 4. 品牌概念 / 节气转场海报

样本特征：品牌 Logo 做 3D 材质化处理（玻璃、水晶、金属），置入唯美自然场景（秋日湖景、枫叶、流水），Logo 本身就是主视觉。

结构公式：Logo 3D 化居中 → 自然场景环绕（季节元素）→ 节气书法字 → 英文衬线大字 → 底部信息栏

色调跟随节气：秋分=暖橙金、夏=青蓝、冬=冷银蓝

### 5. 节日海报（中秋样本）

样本特征：节日符号堆叠（满月、玉兔、灯笼、烟花、月饼）+ 场景化（银色亭台楼阁），暖金主调，插画感与 3D 混合。

结构公式：节日符号营造氛围 → 主题物（月饼/礼物）C 位 → 书法标题 → 信息栏

## 通用版式规律（所有类型适用）

1. 品牌 Logo 固定左上，场地英文名右上
2. 主视觉占中部 60-70%
3. 大字标题在主视觉下方 1/3 处压图
4. 最底部为信息栏（地址、电话、社媒、二维码）
5. 排版虽有套路但**不由 Skill 执行**——只预留区域，用户后期排版

## 对 Skill 的修正

- 「转场海报」细分为：节气/季节转场（Logo 3D+自然场景）与主题夜切换
- 酒水海报分两种气质：高级质感型 vs 促销活泼型，设计前需确认走哪种
