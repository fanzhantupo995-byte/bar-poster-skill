# 视觉提炼维度

从参考图提炼视觉时，按以下五个维度拆解，输出结构化描述，再组装进生图 Prompt。

## 1. 画面结构

- 主视觉位置：居中 / 三分法 / 上下分割 / 对角线
- 空间层次：前景（人物、产品）→ 中景（场景元素）→ 背景（氛围）
- 视线引导：光源方向、透视消失点、人物视线方向
- 留白：文字预留区的位置和大小

## 2. 光影

- 光源类型：霓虹灯管、舞台射灯、屏幕光、轮廓光、体积光
- 光源方向：正面打光 / 侧逆光 / 底光 / 多点霓虹
- 明暗对比：高对比暗调（Club 主流）还是柔和过渡（Livehouse 常见）
- 氛围元素：烟雾、颗粒、光斑、反射地面

## 3. 色彩

- 主色调：暗色基调（黑、深蓝、深紫）上的强调色选择
- 强调色：霓虹粉、电光蓝、酸性绿、橙红等高饱和色
- 明度关系：背景压暗、主体提亮、强调色点缀
- 色彩情绪：迷幻 / 硬核 / 复古 / 高级感

## 4. 排版（仅预设计）

- 版式骨架：文字块的位置分布（顶部 / 底部 / 侧边 / 环绕）
- 字体气质：粗黑冲击力 / 细体高级感 / 手写涂鸦 / 展示字体
- 信息层级：主标题 → 副标题 → 信息区 → Logo 位
- 预留区标注：在生成的背景图上标出各文字区位置和占比

## 5. 融合元素

- Logo 融合：Logo 发光处理、融入场景光源、压印纹理
- IP 融合：角色入画、与场景互动、作为主视觉
- 人物融合：写真照片的风格化处理（色调统一、光影匹配、边缘融合）
- 产品融合：酒水 PNG 的光影匹配、场景置入、氛围渲染
